# MediaAluno

🎓 Cálculo de Média de Alunos
Sistema simples e funcional para calcular a média de notas de alunos, com interface web. O projeto permite cadastrar alunos, inserir notas, calcular a média automaticamente e exibir a situação final: Aprovado, Recuperação ou Reprovado.

🌐 Tecnologias Utilizadas
💻 Python – Backend e lógica de cálculo

🖼️ HTML/CSS – Interface web simples e responsiva

🗄️ SQL (SQLite/MySQL/PostgreSQL) – Banco de dados para armazenar alunos e notas

Funcionalidades
Cadastro de alunos

Inserção de notas

Cálculo automático da média

Exibição da situação final do aluno

Interface web para facilitar o uso
